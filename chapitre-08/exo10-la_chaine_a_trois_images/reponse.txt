Il s’agit d’une séquence simulée pour documenter le cycle, pas d’une capture de ma salle RIHEN réelle.

Le minimum d’images : Le minimum dépend de L. Quand L vaut 0, une image suffit ; quand L vaut 1, deux images suffisent ; quand L vaut 2, il faut au moins trois images pour éviter de réutiliser une image encore lue. Les conflits affichés par le programme permettent de le vérifier.

Sur le simulateur : Le simulateur termine la lecture après la soumission, donc L vaut 0. Trois images ne sont pas nécessaires pour éviter un conflit dans ce modèle, mais elles permettent de conserver le même cycle de plusieurs images que celui utilisé avec un runtime réel.
